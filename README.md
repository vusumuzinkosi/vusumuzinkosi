## Approach

- **Decision first.** Each project defines who will use the result, what they will do with it, and what a wrong answer costs.
- **Measured against a baseline.** Every model is compared with a simple rule, such as "same as last week" or "flag nothing", so any gain is real.
- **Honest validation.** Time-based splits and walk-forward testing, using only information available when the decision is made.
- **Sized to capacity.** Outputs match what a team can act on, such as 300 fraud reviews a day or a call list for 10% of customers.
- **Limitations stated.** Each repository documents what the analysis cannot show and the recommended next steps.
